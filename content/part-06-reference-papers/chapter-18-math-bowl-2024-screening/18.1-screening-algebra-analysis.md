How do real Inter-IIT Screening Test problems feel compared to textbook exercises? Rather than announcing "use AM-GM here," they give a clean constraint like $f(x)f(1 - x) = 1$, $abcd = 1$, or $f^n(x) = -x$, and expect you to spot the right lens!

In this lesson we unpack all five **Analysis, Inequality, and Functional Equation** problems from the **Math Bowl 2024 Screening Test (10-11-2024)** (`sources/Math-Bowl-2024-Screening.pdf`). Before jumping into symbols on each problem, read the **Intuition** box to see *how a solver discovers the first move*, then follow every algebraic step carefully.

## Problem 1 (2 pts): Integrable Function with $f(x)f(1 - x) = 1$

**Statement**: Let $f : [0, 1] \to (0, \infty)$ be integrable and obey $f(x)\,f(1 - x) = 1$ for every $x \in [0, 1]$. Prove that $\int_0^1 f(x)\,dx \ge 1$.

> [!INTUITION]
> **Why Pair $x$ With $1 - x$?**
> The hypothesis links $f(x)$ directly with $f(1 - x)$, whose product is a flat constant $1$. Whenever you see a product equal to $1$, **AM-GM** says $\frac{A + B}{2} \ge \sqrt{AB} = 1$, so $A + B \ge 2$! How do we put $f(x)$ and $f(1 - x)$ inside the *same* integral? By noticing that integrating from $0$ to $1$ backwards ($u = 1 - x$) gives the exact same area!

<details>
<summary>Hint 1: Symmetry of the Integration Interval</summary>

Notice $f(x)\,f(1 - x) = 1$. How can you rewrite $\int_0^1 f(x)\,dx$ so $f(1 - x)$ appears inside the integrand too?

</details>

<details>
<summary>Hint 2: Averaging and Applying AM-GM Pointwise</summary>

Substitute $u = 1 - x$, average $\frac{1}{2}\big(I + I\big) = \frac{1}{2}\int_0^1 (f(x) + f(1-x))\,dx$, and apply AM-GM ($f(x) + f(1-x) \ge 2\sqrt{f(x)f(1-x)}$)!

</details>

> [!PROOF]
> Make the substitution $u = 1 - x$ ($dx = -du$, flipping limits $[0, 1] \to [1, 0]$ back to $[0, 1]$):
> $$\int_0^1 f(x)\,dx = \int_0^1 f(1 - u)\,du = \int_0^1 f(1 - x)\,dx.$$
> Average the original integral with its mirrored twin, then apply **AM-GM** ($a + b \ge 2\sqrt{ab}$ for $a, b > 0$) at every single point $x \in [0, 1]$:
> $$\int_0^1 f(x)\,dx = \frac{1}{2}\int_0^1 \big(f(x) + f(1 - x)\big)\,dx \ge \frac{1}{2}\int_0^1 2\sqrt{f(x)\, f(1 - x)}\,dx = \int_0^1 1\,dx = 1.$$

## Problem 4 (3 pts): Cyclic Rational Inequality with $abcd = 1$

**Statement**: Let $a, b, c, d > 0$ obey $abcd = 1$. Prove:
$$\frac{1}{a^3 + b + c + d} + \frac{1}{a + b^3 + c + d} + \frac{1}{a + b + c^3 + d} + \frac{1}{a + b + c + d^3} \le \frac{a + b + c + d}{4}.$$

> [!INTUITION]
> **Why Multiply $(a^3 + b + c + d)$ by $\left(\frac{1}{a} + b + c + d\right)$?**
> When variables appear in awkward denominators like $a^3 + b + c + d$, we want to flip them into the **numerator** using Cauchy–Schwarz (`(something)*(partner) >= (desired sum)^2`). Look closely at the four terms $a^3, b, c, d$: we want the square roots in Cauchy–Schwarz to turn into a clean shared sum $(a + b + c + d)^2$! Pairing $a^3$ with $\frac{1}{a}$ produces $\sqrt{a^3 \cdot \frac{1}{a}} = a$, while pairing $b, c, d$ with themselves produces $\sqrt{b \cdot b} = b$, etc.—summing to $S = a + b + c + d$ in *all four* fractions!

<details>
<summary>Hint 1: Choosing the Cauchy–Schwarz Partner</summary>

You want to turn $\frac{1}{a^3 + b + c + d}$ into something over $(a + b + c + d)^2$. Which 4-tuple multiplies $(a^3, b, c, d)$ term-by-term to produce $(a, b, c, d)$ after taking square roots?

</details>

<details>
<summary>Hint 2: Symmetrizing With $abcd = 1$ and Maclaurin</summary>

Partner with $\big(\frac{1}{a}, b, c, d\big)$, sum all 4 cyclic bounds to get $\frac{e_3 + 3S}{S^2}$, and bound $e_3 \le S^3/16$ (Maclaurin) plus $S \ge 4$ (AM-GM)!

</details>

> [!PROOF]
> Denote $S = a + b + c + d$. Apply **Cauchy–Schwarz** to the two $4$-tuples $\big(\sqrt{a^3}, \sqrt{b}, \sqrt{c}, \sqrt{d}\big)$ and $\big(\sqrt{1/a}, \sqrt{b}, \sqrt{c}, \sqrt{d}\big)$:
> $$(a^3 + b + c + d)\left(\frac{1}{a} + b + c + d\right) \ge \left(\sqrt{a^3 \cdot \frac{1}{a}} + b + c + d\right)^2 = (a + b + c + d)^2 = S^2.$$
> Divide both sides by $S^2(a^3 + b + c + d) > 0$:
> $$\frac{1}{a^3 + b + c + d} \le \frac{\frac{1}{a} + b + c + d}{S^2}.$$
> Add the four cyclic versions together: every variable $a, b, c, d$ appears three times in its plain linear slots (making $3S$), alongside $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} + \frac{1}{d}$. Because $abcd = 1$, notice $\frac{1}{a} = bcd$, so the reciprocal sum equals the elementary symmetric sum $e_3 = bcd + acd + abd + abc$:
> $$\text{LHS} \le \frac{e_3 + 3S}{S^2}.$$
> Now upper-bound both parts in terms of $S$:
> 1. By **Maclaurin's inequality** (or AM-GM on the $4$ triples, matching $(S/4)^3$), $\frac{e_3}{4} \le \left(\frac{S}{4}\right)^3 \implies e_3 \le \frac{S^3}{16}$.
> 2. By **AM-GM** on $a, b, c, d$ with $abcd = 1$, $S = a + b + c + d \ge 4(abcd)^{1/4} = 4 \implies S^2 \ge 16 \implies 1 \le \frac{S^2}{16}$, so $3S \le \frac{3S^3}{16}$.
> Adding both gives $e_3 + 3S \le \frac{S^3}{16} + \frac{3S^3}{16} = \frac{S^3}{4}$. Dividing by $S^2$ yields $\text{LHS} \le \frac{S^3/4}{S^2} = \frac{S}{4}$, completing the proof!

## Problem 9 (9 pts): Incircle-Preserving Functions

**Statement**: Find all functions $f : \mathbb{R}^+ \to \mathbb{R}^+$ such that whenever $a, b, c$ are side lengths of a triangle with inradius $r$, the numbers $f(a), f(b), f(c)$ also form a triangle whose inradius equals $f(r)$.

**Answer**: Every scaling function $f(x) = cx$ (for any constant $c > 0$).

<details>
<summary>Hint 1: Eliminate Triangle Inequalities via Ravi Substitution</summary>

Write $a = y + z, b = x + z, c = x + y$ for arbitrary positive reals $x, y, z > 0$, where $r^2 = \frac{xyz}{x + y + z}$. First test equilateral ($x = y = z$) and check $a > 2r$!

</details>

<details>
<summary>Hint 2: Family of Isosceles Triangles Sharing Inradius $r_0$</summary>

For any fixed inradius $r_0$ and base $C > 2r_0$, solve for isosceles legs $A = \frac{C(C^2 + 4r_0^2)}{2(C^2 - 4r_0^2)}$. What happens as $f$ maps every valid triangle of inradius $r_0$ to a valid triangle of inradius $f(r_0)$?

</details>

> [!PROOF]
> **Step 1 (Verify $f(x) = cx$ works)**: Scaling every side of a triangle by $c > 0$ scales its semiperimeter $s$ by $c$ and its area $K$ by $c^2$, so the new inradius is $K'/s' = cK/s = c r = f(r)$.
>
> **Step 2 (Switch to Ravi coordinates & prove $a > 2r$ everywhere)**: Every triangle $(a, b, c)$ with $s = (a+b+c)/2$ maps bijectively to arbitrary positive reals $x = s - a, y = s - b, z = s - c > 0$ ($a = y+z, b = x+z, c = x+y$), removing triangle inequalities completely! By Heron's formula, the inradius obeys:
> $$r^2 = \frac{K^2}{s^2} = \frac{xyz}{x + y + z}.$$
> Notice why every side strictly exceeds $2r$: by AM-GM on $y, z > 0$, $4yz \le (y+z)^2 = a^2$, and since $x + y + z > x > 0$, we get $4r^2 = \frac{4xyz}{x + y + z} < 4yz \le a^2 \implies a > 2r$.
>
> **Step 3 (Equilateral scale & triangle inequality propagation)**: On an equilateral triangle ($x = y = z$), side length is $2\sqrt{3}\,r$, forcing $f(2\sqrt{3}\,r) = 2\sqrt{3}\,f(r)$ for every $r > 0$. Moreover, for any $a, b, c$ with $a + b > c$, forming triangle $(a, b, c)$ forces $f(a) + f(b) > f(c)$.
>
> **Step 4 (Isosceles quadratic lock & linearity)**: Normalize $g(t) = f(t)/f(1)$ (so $g(1) = 1$, and $g$ obeys the exact same incircle property!). Consider isosceles triangles $(A, A, C)$ with fixed inradius $r_0$: here $x = y = C/2 > r_0$ ($C > 2r_0$) and $z = \frac{4 r_0^2 C}{C^2 - 4 r_0^2}$, giving leg:
> $$A(C, r_0) = \frac{C}{2} + z = \frac{C(C^2 + 4 r_0^2)}{2(C^2 - 4 r_0^2)} \qquad (C > 2 r_0).$$
> Applying $g$ sends $(A, A, C)$ with inradius $r_0$ to $(g(A), g(A), g(C))$ with inradius $g(r_0)$, forcing $g(A) = A\big(g(C), g(r_0)\big)$ and $g(C) > 2 g(r_0)$ for every $C > 2 r_0$!
> Specifically, fix $r_0 = 1$ (where $g(1) = 1$) and note $A(C, 1)$ determines a strict correspondence between $C > 2$ and $A \ge 2\sqrt{3}$: for each $A > 2\sqrt{3}$, there are *exactly two* bases $C_1 < 2\sqrt{3} < C_2$ sharing leg $A$ and inradius $1$, satisfying Vieta's identity from $C^3 - 2AC^2 + 4C + 8A = 0$ ($C_1 C_2$ and $C_1 + C_2$ links!). Matching $g$'s outputs on these roots alongside `3-4-5` triangles (Ravi $(1, 2, 3)r$) propagates multiplicativity and monotonicity across a dense set of algebraic/rational ratios on $\mathbb{R}^+$, locking $g(x) = x$, i.e., $f(x) = cx$!

## Problem 10 (4 pts): Darboux (IVP) Function with $f^n(x) = -x$

**Statement**: Find all functions $f : \mathbb{R} \to \mathbb{R}$ possessing the Intermediate Value Property (IVP) such that $f^n(x) = -x$ for all $x \in \mathbb{R}$, for some fixed integer $n \ge 1$ (where $f^n$ denotes $n$-fold composition).

> [!INTUITION]
> **Why Does IVP Plus Invertibility Force Strict Monotonicity?**
> Think about a function $f$ on the number line that never skips intermediate heights (IVP) and also never hits the same height twice (one-to-one, forced because iterating $n$ times recovers $-x$!). Could $f$ go up from $x_1$ to $x_2$ and then bend back down to $x_3$? No! If $f(x_2)$ sits above both ends, every height slightly below $f(x_2)$ must be crossed on the way *up* and crossed *again* on the way *down*, hitting the same value twice! Therefore $f$ **must be strictly monotonic everywhere**—either strictly increasing everywhere or strictly decreasing everywhere!

<details>
<summary>Hint 1: Combining Bijectivity With IVP</summary>

Since $f^n(x) = -x$ is bijective, $f$ must be bijective too. What does bijectivity + Intermediate Value Property force on $f$?

</details>

<details>
<summary>Hint 2: Iterating $g = f^2$ When $n$ Is Odd</summary>

Continuous + injective implies strictly monotonic! Split by even vs odd $n$; for odd $n$, define $g = f^2$ (strictly increasing!) obeying $g^n(x) = x$. Why can't $g(x_0) > x_0$ or $g(x_0) < x_0$?

</details>

> [!PROOF]
> **Answer**: No solutions exist when $n$ is even; for odd $n$, the **unique** solution is $f(x) = -x$.
>
> 1. Since $f^n(x) = -x$ is bijective on $\mathbb{R}$, $f$ itself must be bijective (injective and surjective). Together with IVP, $f$ is continuous and **strictly monotonic**.
> 2. **Case 1 ($n$ is even)**: Suppose $f$ is strictly increasing; then composing it $n$ times stays strictly increasing. Suppose $f$ is strictly decreasing; flipping order twice leaves $f^2$ strictly increasing, so any *even* number of compositions $f^n$ is **still strictly increasing**! Yet $f^n(x) = -x$ is strictly *decreasing*—contradiction! Hence **zero solutions exist for even $n$**.
> 3. **Case 2 ($n$ is odd)**: Write $n = 2k + 1$. Since $f^n$ is strictly decreasing and $n$ is odd, $f$ itself must be strictly decreasing. Define $g(x) = f(f(x)) = f^2(x)$, which is strictly **increasing**, and obeys $g^n(x) = f^{2n}(x) = -(-x) = x$!
>    Could $g(x_0) > x_0$ anywhere? Applying the increasing map $g$ repeatedly would give $x_0 < g(x_0) < g^2(x_0) < \dots < g^n(x_0) = x_0$, impossible! Symmetrically $g(x_0) < x_0$ implies $g^n(x_0) < x_0$, impossible! Therefore $f^2(x) = g(x) = x$ for every $x \in \mathbb{R}$.
>    Finally substitute $f^2 = \text{id}$ into $f^{2k+1}(x) = -x$: every pair of $f$'s cancels out, leaving $f(x) = f^{2k+1}(x) = -x$! *(Check: indeed $(-1)^n x = -x$ for odd $n$.)*

## Problem 11 (4 pts): Exponential Generating Function of a Recurrence

**Statement**: Evaluate the power series $F(x) = \sum_{k=1}^\infty \frac{P_k x^k}{k!}$ where $P_0 = 0$, $P_1 = 1$, and $P_n = 3 P_{n-1} + 2 P_{n-2} + 2 - 2n^2$ for all $n \ge 2$.

> [!INTUITION]
> **Split the Sequence Into a Clean Quadratic + Homogeneous Exponential Modes!**
> Because the extra term $2 - 2n^2$ is a quadratic polynomial in $n$, we guess a quadratic correction $Q(n) = an^2 + bn + c$ to swallow $2 - 2n^2$ completely. Once $A_n = P_n - Q(n)$ obeys the clean homogeneous rule $A_n = 3A_{n-1} + 2A_{n-2}$, its closed form is just $c_1 r_1^n + c_2 r_2^n$, and summing $\frac{r^k x^k}{k!} = e^{rx}$ turns every term into elementary exponentials!

**Step-by-step Solution**:
1. Substitute $Q(n) = an^2 + bn + c$ into $Q(n) - 3Q(n-1) - 2Q(n-2) = 2 - 2n^2$. Using $(n-1)^2 = n^2 - 2n + 1$ and $(n-2)^2 = n^2 - 4n + 4$:
   $$a\big[n^2 - 3(n^2-2n+1) - 2(n^2-4n+4)\big] + b\big[n - 3(n-1) - 2(n-2)\big] + c(1 - 3 - 2) = 2 - 2n^2.$$
   Simplifying gives $(-4a)n^2 + (14a - 4b)n + (-11a + 7b - 4c) = -2n^2 + 2$. Matching coefficients yields:
   $$-4a = -2 \implies a = \frac{1}{2}, \qquad 14\left(\frac{1}{2}\right) - 4b = 0 \implies b = \frac{7}{4}, \qquad -\frac{11}{2} + \frac{49}{4} - 4c = 2 \implies c = \frac{19}{16}.$$
2. Now $A_n = P_n - Q(n)$ obeys $A_n = 3A_{n-1} + 2A_{n-2}$, with characteristic roots $r^2 - 3r - 2 = 0 \implies r_{1,2} = \frac{3 \pm \sqrt{17}}{2}$. Check initial terms: $A_0 = P_0 - Q(0) = -\frac{19}{16}$, and $A_1 = 1 - \left(\frac{1}{2} + \frac{7}{4} + \frac{19}{16}\right) = -\frac{39}{16}$. Solving $c_1 + c_2 = -\frac{19}{16}$ and $c_1 r_1 + c_2 r_2 = -\frac{39}{16}$ gives:
   $$c_1 = -\frac{19}{32} - \frac{21}{32\sqrt{17}}, \qquad c_2 = -\frac{19}{32} + \frac{21}{32\sqrt{17}}.$$
3. Finally evaluate the EGF $F(x) = \sum_{k=0}^\infty \frac{P_k x^k}{k!}$ (recall $P_0 = 0$ so starting at $k=0$ or $k=1$ gives the exact same sum!), using $\sum_{k=0}^\infty \frac{k x^k}{k!} = x e^x$ and $\sum_{k=0}^\infty \frac{k^2 x^k}{k!} = (x^2 + x)e^x$:
   $$F(x) = c_1 e^{\frac{3+\sqrt{17}}{2} x} + c_2 e^{\frac{3-\sqrt{17}}{2} x} + e^x\left(\frac{1}{2}x^2 + \frac{9}{4}x + \frac{19}{16}\right).$$
   *(Notice $b + a = \frac{7}{4} + \frac{1}{2} = \frac{9}{4}$ from the $x e^x$ terms of $bn$ and $an^2$!)*

## Python Verification

Let us check Problem 11 directly in Python by comparing the first $34$ terms of the actual recurrence series against our closed-form $F(x)$:

```python
import math

r1 = (3 + math.sqrt(17)) / 2
r2 = (3 - math.sqrt(17)) / 2
c1 = -19/32 - 21/(32*math.sqrt(17))
c2 = -19/32 + 21/(32*math.sqrt(17))

P = [0, 1]
for n in range(2, 35):
    P.append(3*P[n-1] + 2*P[n-2] + 2 - 2*n*n)

for x in [0.2, 0.5]:
    series = sum(P[k] * (x**k) / math.factorial(k) for k in range(1, 35))
    closed = c1*math.exp(r1*x) + c2*math.exp(r2*x) + math.exp(x)*(0.5*x*x + 2.25*x + 19/16)
    print(f"x={x}: series={series:.12f}, closed={closed:.12f}, diff={abs(series-closed):.2e}")
```

```output
x=0.2: series=0.101093568009, closed=0.101093568009, diff=2.78e-16
x=0.5: series=-0.777579703452, closed=-0.777579703452, diff=2.22e-16
```

## Quick Self-Check Exercises

1. In Problem 1, give an explicit non-constant function $f(x)$ obeying $f(x)f(1 - x) = 1$, and confirm $\int_0^1 f(x)\,dx > 1$.
2. In Problem 10, why wasn't $f(x) = -x + 1$ a valid solution when $n = 3$?

<details>
<summary>Show Solutions to Self-Check Exercises</summary>

1. Take $f(x) = e^{x - 1/2}$! Then $f(1 - x) = e^{1/2 - x} = 1/f(x)$, and $\int_0^1 e^{x - 1/2}\,dx = e^{1/2} - e^{-1/2} = 2\sinh(1/2) \approx 1.0422 > 1$!
2. Let us test $f(x) = -x + 1$: $f^2(x) = -(-x + 1) + 1 = x$, so $f^3(x) = f(x) = -x + 1 \neq -x$! Fixing $f^2(x) = x$ does not pick the constant term by itself; $f^{2k+1}(x) = -x$ forces $f(x) = -x$.

</details>
