While the Screening Test checks speed across 18 shorter questions, the **CMI Inter-IIT Tech Fest Mathematical Competition 2023** (`sources/CMI-Inter-IIT-Math-Bowl-2023-Soln.pdf`) asks for deep, polished Olympiad proofs across 5 challenging problems. Notice the encouraging secret behind Problems 1–3 below: every single one cracks open using a tool we already practiced in **Toolkit §0.2**—Rayleigh quotients for symmetric matrices, Cauchy–Schwarz for cyclic roots, and Cantor diagonalization separating countable $\mathbb{Q}$ from uncountable $\mathbb{R}$!

## CMI Problem 1 (2018 South Korea USCM P5): Symmetric Matrix Eigenvalue Range

**Statement**: Let $A = (a_{ij})$ be a real symmetric $2023 \times 2023$ matrix whose entries satisfy $|a_{ij} - 2023| \le 1$ (meaning $2022 \le a_{ij} \le 2024$) for all $1 \le i, j \le 2023$. Find the minimum and maximum possible values of its largest eigenvalue $\lambda(A)$.

**Answer**: Minimum possible $\lambda(A) = 2022 \times 2023 = 4{,}090{,}506$, and maximum possible $\lambda(A) = 2024 \times 2023 = 4{,}094{,}552$.

> [!INTUITION]
> **Two Completely Naive Moves Trap the Eigenvalue From Below and Above!**
> What is the simplest matrix in `[2022, 2024]`? Making *every* entry equal to $2022$, or every entry equal to $2024$! For a flat constant $c J$ matrix ($2023 \times 2023$), the vector of all $1$'s has eigenvalue $2023 c$ (and all other eigenvalues $0$). That immediately guesses our two extreme values: $2022 \times 2023$ and $2024 \times 2023$. Now we just prove nothing can go lower than $2022 \times 2023$ (by testing the Rayleigh quotient on $\mathbf{1}$) and nothing can go higher than $2024 \times 2023$ (via Cauchy–Schwarz on rows)!

<details>
<summary>Hint 1: Guessing and Bounding Lower Limit With One Test Vector</summary>

Check the constant matrices $2022 J$ and $2024 J$ first. To prove $\lambda(A) \ge 2022 \times 2023$ for *any* $A$ in the box, plug the normalized all-ones vector $u$ into the Rayleigh quotient $\langle Au, u \rangle$!

</details>

<details>
<summary>Hint 2: Row-Wise Cauchy–Schwarz for the Upper Bound</summary>

For a unit eigenvector $v$ ($Av = \lambda v$), bound $\lambda^2 = \sum_i (\sum_j a_{ij} v_j)^2$ via Cauchy–Schwarz on each row using $|a_{ij}| \le 2024$!

</details>

> [!PROOF]
> Because $A$ is real symmetric, all eigenvalues are real, and by **Rayleigh's theorem** (Toolkit §0.2), its largest eigenvalue obeys $\lambda(A) = \max_{\|v\|_2 = 1} \langle Av, v \rangle$.
> 1. **Lower bound ($\lambda(A) \ge 2022 \times 2023$)**: Pick the normalized all-ones vector $u = \frac{1}{\sqrt{2023}}(1, 1, \dots, 1)^{\mathsf{T}}$ ($\|u\|_2 = 1$). Since every $a_{ij} \ge 2022$:
>    $$\lambda(A) \ge \langle Au, u \rangle = \frac{1}{2023}\sum_{i=1}^{2023}\sum_{j=1}^{2023} a_{ij} \ge \frac{2023^2 \cdot 2022}{2023} = 2022 \times 2023.$$
> 2. **Upper bound ($\lambda(A) \le 2024 \times 2023$)**: Notice $|a_{ij}| \le 2024$ for every entry. For any unit eigenvector $v$ ($Av = \lambda(A) v$, $\|v\|_2 = 1$), apply **Cauchy–Schwarz** to each row sum $\sum_j a_{ij} v_j$:
>    $$\lambda(A)^2 = \|Av\|_2^2 = \sum_{i=1}^{2023} \left(\sum_{j=1}^{2023} a_{ij} v_j\right)^2 \le \sum_{i=1}^{2023} \left(\sum_{j=1}^{2023} a_{ij}^2\right)\left(\sum_{j=1}^{2023} v_j^2\right) \le 2023 \cdot (2023 \cdot 2024^2) \cdot 1 = (2024 \times 2023)^2.$$
>    Taking square roots leaves $\lambda(A) \le 2024 \times 2023$.
> 3. **Attainability**: Both bounds are actually reached! Take $A = 2022 J$ ($J$ all-ones) for largest eigenvalue $2022 \times 2023$, and $A = 2024 J$ for $2024 \times 2023$!

## CMI Problem 2 (Serbian NMO 2017): Symmetric Square-Root Inequality

**Statement**: For positive real numbers $a, b, c$ with $a + b + c = 1$, prove:
$$a\sqrt{2b + 1} + b\sqrt{2c + 1} + c\sqrt{2a + 1} \le \sqrt{2 - (a^2 + b^2 + c^2)}.$$

> [!INTUITION]
> **Split Each $a$ Across Both Halves of Cauchy–Schwarz: $a = \sqrt{a} \cdot \sqrt{a}$!**
> Look under the square root on the right side: using $a + b + c = 1$, notice $2 - (a^2 + b^2 + c^2) = 1 + \big((a+b+c)^2 - (a^2+b^2+c^2)\big) = 1 + 2(ab + bc + ca)$! How can the left-hand sum $a\sqrt{2b + 1} + \dots$ square into $(a + b + c) \cdot \big(2(ab + bc + ca) + a + b + c\big)$? Put one factor $\sqrt{a}$ into the first vector and keep $\sqrt{a(2b+1)}$ inside the second vector!

> [!PROOF]
> Apply **Cauchy–Schwarz** to $x = (\sqrt{a}, \sqrt{b}, \sqrt{c})$ and $y = \big(\sqrt{a(2b + 1)},\; \sqrt{b(2c + 1)},\; \sqrt{c(2a + 1)}\big)$:
> $$\left(a\sqrt{2b + 1} + b\sqrt{2c + 1} + c\sqrt{2a + 1}\right)^2 \le (a + b + c)\big(a(2b + 1) + b(2c + 1) + c(2a + 1)\big).$$
> Since $a + b + c = 1$, the first factor disappears cleanly ($= 1$), leaving:
> $$2(ab + bc + ca) + (a + b + c) = \big((a + b + c)^2 - (a^2 + b^2 + c^2)\big) + 1 = 1 - (a^2 + b^2 + c^2) + 1 = 2 - (a^2 + b^2 + c^2).$$
> Taking positive square roots gives the target inequality immediately!

## CMI Problem 3 (IMC 2003): Bounding $f(x, y) \le g(x) + g(y)$ on $\mathbb{Q}$ vs $\mathbb{R}$

**Statement**:
1. Prove that for *every* function $f : \mathbb{Q} \times \mathbb{Q} \to \mathbb{R}$, there exists $g : \mathbb{Q} \to \mathbb{R}$ obeying $f(x, y) \le g(x) + g(y)$ for all $x, y \in \mathbb{Q}$.
2. Construct a function $f : \mathbb{R} \times \mathbb{R} \to \mathbb{R}$ for which **no** function $g : \mathbb{R} \to \mathbb{R}$ satisfies $f(x, y) \le g(x) + g(y)$ for all $x, y \in \mathbb{R}$.

> [!INTUITION]
> **Why Does Countability Let Us Build $g$ Step-by-Step While Uncountability Breaks It?**
> - **On $\mathbb{Q}$ (Countable)**: You can line up every rational number in a single infinite queue $q_1, q_2, q_3, \dots$! As you reach $q_i$, you only need $g(q_i)$ to beat the *finite* table of pairs $(q_u, q_v)$ with $u, v \le i$—so setting $g(q_i)$ bigger than $\max_{u,v \le i} f(q_u, q_v)$ handles every pair $(q_i, q_j)$ by the time the *later* of $i$ and $j$ arrives!
> - **On $\mathbb{R}$ (Uncountable)**: There are way too many real numbers to line up! In fact, because there are just as many real numbers as **infinite sequences of positive integers** ($|\mathbb{R}| = |\mathbb{N}^\mathbb{N}|$), each real $x$ can encode its *own custom counterexample sequence* $x \leftrightarrow (\sigma(x)(1), \sigma(x)(2), \dots)$—so for *any* challenger $g$, some real number $r$ encodes a sequence growing faster than $g(n) + g(r)$!

<details>
<summary>Hint 1: Compare Countability of $\mathbb{Q}$ vs Bijections $\mathbb{R} \leftrightarrow \mathbb{N}^\mathbb{N}$</summary>

On $\mathbb{Q}$, enumerate $q_1, q_2, \dots$ and make $g(q_i)$ dominate the *finite* table $S_i \times S_i$. On $\mathbb{R}$, remember $|\mathbb{R}| = |\mathbb{N}^\mathbb{N}|$: encode an entire sequence $\sigma(x) \in \mathbb{N}^\mathbb{N}$ inside each real $x$!

</details>

<details>
<summary>Hint 2: Diagonalize Against Any Candidate $g$</summary>

Set $f(x, y) = \sigma(x)(y)$ when $y \in \mathbb{N}$. Given *any* candidate $g$, build $h(n) = \lceil \max(0, g(n)) + n \rceil$, decode $r = \sigma^{-1}(h)$, and pick natural number $m > g(r)$!

</details>

> [!PROOF]
> **Part 1 (Over $\mathbb{Q}$)**: Enumerate the rationals $\mathbb{Q} = \{q_1, q_2, \dots\}$ and define finite prefixes $S_i = \{q_1, \dots, q_i\}$. For each $i \ge 1$, take a finite maximum:
> $$g(q_i) = \max\Big(0,\; \max_{(u, v) \in S_i \times S_i} f(u, v)\Big).$$
> Now pick any two rationals $q_i, q_j \in \mathbb{Q}$, and set $m = \max(i, j)$. Notice $(q_i, q_j) \in S_m \times S_m$, so $f(q_i, q_j) \le g(q_m)$. Because every $g(q) \ge 0$, adding the other nonnegative term $g(q_{\min(i,j)}) \ge 0$ guarantees $f(q_i, q_j) \le g(q_i) + g(q_j)$!
>
> **Part 2 (Over $\mathbb{R}$)**: Since $|\mathbb{R}| = |2^\mathbb{N}| = |\mathbb{N}^\mathbb{N}|$, pick a bijection $\sigma : \mathbb{R} \to \mathbb{N}^\mathbb{N}$ assigning each real $x$ to a sequence of positive integers $\sigma(x)(1), \sigma(x)(2), \dots$. Construct:
> $$f(x, y) = \begin{cases} \sigma(x)(y) & \text{if } y \in \mathbb{N}, \\ 0 & \text{otherwise.} \end{cases}$$
> Suppose any function $g : \mathbb{R} \to \mathbb{R}$ tried to beat $f$. Notice $g$ restricted to natural numbers $n = 1, 2, 3, \dots$ produces a sequence $g(1), g(2), \dots$, so we can cook up the sequence $h \in \mathbb{N}^\mathbb{N}$ defined by:
> $$h(n) = \lceil \max(0, g(n)) + n \rceil \in \mathbb{N}.$$
> Let $r = \sigma^{-1}(h) \in \mathbb{R}$ be the real number encoding this sequence $h$, and choose a positive integer $m > g(r)$. Plug $(r, m)$ into $f$:
> $$f(r, m) = \sigma(r)(m) = h(m) \ge g(m) + m > g(m) + g(r),$$
> directly violating $f(r, m) \le g(r) + g(m)$!

## Python Check for CMI P1 & P2

Let us test a scaled-down $10 \times 10$ symmetric matrix version of CMI P1 (entries in `[9, 11]`, eigenvalues trapped in `[90, 110]`) and check random $(a,b,c)$ triples for CMI P2 in Python:

```python
import numpy as np
import random

# 1. CMI P1 check on smaller n=10 matrix with entries in [9, 11] (analog of [2022, 2024])
n = 10
A = np.full((n, n), 10.0) + np.random.default_rng(0).uniform(-1, 1, (n, n))
A = 0.5 * (A + A.T)
lam_max = np.max(np.linalg.eigvalsh(A))
print(f"n={n} symmetric entries in [9,11]: lambda_max={lam_max:.3f}, bounds=[{9*n}, {11*n}]")

# 2. CMI P2 check for random (a,b,c) summing to 1
random.seed(5)
for _ in range(3):
    u = [random.random() + 0.1 for _ in range(3)]
    a, b, c = [x / sum(u) for x in u]
    lhs = a*(2*b+1)**0.5 + b*(2*c+1)**0.5 + c*(2*a+1)**0.5
    rhs = (2 - (a*a + b*b + c*c))**0.5
    print(f"P2: LHS={lhs:.6f} <= RHS={rhs:.6f}")
```

```output
n=10 symmetric entries in [9,11]: lambda_max=101.001, bounds=[90, 110]
P2: LHS=1.289785 <= RHS=1.289998
P2: LHS=1.289608 <= RHS=1.289851
P2: LHS=1.221505 <= RHS=1.236197
```

## Quick Self-Check Exercises

1. In CMI Problem 2, **when does exact equality** hold in $a\sqrt{2b + 1} + b\sqrt{2c + 1} + c\sqrt{2a + 1} \le \sqrt{2 - (a^2 + b^2 + c^2)}$?
2. Why did we need $m > g(r)$ at the very last line of CMI Problem 3 (Part 2)?

<details>
<summary>Show Solutions to Self-Check Exercises</summary>

1. Equality in Cauchy–Schwarz between $(\sqrt{a}, \sqrt{b}, \sqrt{c})$ and $(\sqrt{a(2b+1)}, \sqrt{b(2c+1)}, \sqrt{c(2a+1)})$ occurs iff the coordinate ratios are equal: $2b + 1 = 2c + 1 = 2a + 1$, forcing $a = b = c = \frac{1}{3}$! Check: LHS $= \sqrt{5/3}$, RHS $= \sqrt{2 - 1/3} = \sqrt{5/3}$.
2. Because $r = \sigma^{-1}(h)$ only gets fixed *after* $h$ is built, $g(r)$ could be huge (like $10^{500}$), even though we don't know $g(r)$ while defining $h$! By including $+n$ inside $h(n) \ge g(n) + n$, $h(m)$ automatically defeats $g(m) + g(r)$ as soon as we simply evaluate at any natural number $m$ larger than $g(r)$!

</details>
