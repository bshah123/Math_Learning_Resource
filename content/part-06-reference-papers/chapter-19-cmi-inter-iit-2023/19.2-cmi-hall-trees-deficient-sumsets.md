Look closely at the final two flagship problems of the **CMI Inter-IIT Math Bowl 2023**: Problem 4 uses **Hall's Marriage Theorem** (from Lesson 1.2) to extract proper color classes out of a red/blue edge-colored graph, while Problem 5 uses **primorials + the Prime Number Theorem** (from Lesson 9.1) to grow an infinite set whose pairwise sums are always *deficient*! Notice again how clearly each proof flows once the central trick is revealed in plain English first.

## CMI Problem 4 (Miklós Schweitzer 2012): Monochromatic Tree via Hall's Theorem

**Statement**: Let $G = (V, E)$ be a simple graph requiring $k$ colors to properly color its vertices ($\chi(G) = k$). Color every edge of $G$ either Red or Blue. Prove that $G$ contains a monochromatic tree on at least $k$ vertices.

> [!INTUITION]
> **Why Assume Every Monochromatic Piece Is Small ($\le k - 1$) and Build a Forbidden $(k-1)$-Coloring?**
> Suppose every connected Red island $R_i$ and every connected Blue island $B_j$ had size strictly below $k$ (at most $k - 1$). Could two vertices inside *different* Red islands AND *different* Blue islands ever be joined by an edge in $G$? **Impossible!** Any edge must be Red (staying inside one $R_i$) or Blue (staying inside one $B_j$)! Therefore, if we can give each color $1, \dots, k - 1$ to **one vertex per Red island and one vertex per Blue island**, those vertices form a completely edge-free **independent set**! Using **Hall's Marriage Theorem** to match Red islands one-to-one with Blue islands peels off color classes layer by layer, properly $(k-1)$-coloring $G$ and contradicting $\chi(G) = k$!

> [!PROOF]
> Proceed by contradiction: suppose every Red connected component $R_1, \dots, R_m$ and every Blue connected component $B_1, \dots, B_n$ has size $\le k - 1$ (if any had size $\ge k$, any spanning tree of it contains a $k$-vertex monochromatic tree!).
>
> First pad $G$ smoothly so every piece has exact equal size $\ell = k - 1$: add isolated vertices (which don't create monochromatic trees and cannot lower $\chi(G)$) into small components and add dummy empty-edge components of size $\ell$ until $m = n$ and $|R_i| = |B_j| = \ell$ for all $i, j$, partitioning `[m * l]`.
>
> We finish by proving a clean general Claim by induction on $\ell \ge 1$:
> **Claim**: Given any two partitions $R_1, \dots, R_m$ and $B_1, \dots, B_m$ of `[m * l]` into blocks of equal size $\ell$, we can color `[m * l]` using $\ell$ colors so that every Red block $R_i$ and every Blue block $B_j$ sees all $\ell$ distinct colors once each!
> - **Base case ($\ell = 1$)**: Every block has size $1$; color every vertex with color $1$.
> - **Inductive step ($\ell = t \ge 2$)**: Form a bipartite graph putting Red components $\{R_1, \dots, R_m\}$ on the Left and Blue components $\{B_1, \dots, B_m\}$ on the Right, drawing an edge $(R_i, B_j)$ whenever they share at least one vertex ($R_i \cap B_j \neq \emptyset$).
>   Does Hall's condition (Lesson 1.2) hold? Pick any $j$ Red blocks on the Left: together they contain $j t$ distinct elements. Since each Blue block on the Right can swallow at most $t$ elements, those $j t$ elements must intersect at least $\lceil jt / t \rceil = j$ different Blue blocks! So Hall's Marriage Theorem gives a **perfect matching** $\pi$ pairing every $R_i$ with a distinct $B_{\pi(i)}$ sharing a vertex $v_i \in R_i \cap B_{\pi(i)}$.
>   Paint all $m$ matched vertices `{v_1, ..., v_m}` with fresh color $t$! Deleting those $m$ vertices shrinks every $R_i$ and every $B_j$ down to size $t - 1$, so by induction the remaining elements get colors $1, \dots, t - 1$ appearing once per block!
>
> Applying the Claim at $\ell = k - 1$ gives a $(k - 1)$-coloring of $G$ where no color repeats inside any $R_i$ or any $B_j$—so no edge connects same-colored vertices! That is a valid proper $(k - 1)$-coloring of $G$, contradicting $\chi(G) = k$.

## CMI Problem 5 (Korea Winter 2018): Infinite Set With Deficient Pairwise Sums

**Statement**: Call a positive integer $n$ **deficient** ("uwu") if the sum of *all* its positive divisors (including $1$ and $n$) satisfies $\sigma(n) < 2n$ (equivalently, $\frac{\sigma(n)}{n} < 2$). Does there exist an infinite set $M \subset \mathbb{Z}_{>0}$ such that $a + b$ is deficient for **every** pair $a, b \in M$ (including $a = b$)?

**Answer**: **Yes!** Build $M$ one element at a time using huge primorials $+ 1$.

> [!INTUITION]
> **Why Does Multiplying by a Giant Primorial + 1 Protect Every Sum?**
> Look at the deficiency ratio $D(n) = \frac{\sigma(n)}{n} = \sum_{d \mid n} \frac{1}{d}$. Two simple truths govern $D(n)$:
> 1. Small primes like $2, 3, 5$ inflate $D(n)$ badly ($1 + \frac{1}{2}$ multiplies by $1.5$, pushing sums over $2$ quickly!), whereas huge primes $> 1000$ barely budge $D(n)$ (multiplying by at most $1 + \frac{1}{p} \approx 1.0009$!).
> 2. Suppose you have already built $M_{i-1} = \{m_1, \dots, m_{i-1}\}$, and you want a giant new number $m_i$ so that $m_i + m$ stays deficient! Write $m_i = L \cdot P_N + 1$, where $P_N = p_1 p_2 \cdots p_N$ is the product of the first $N$ primes and $L$ absorbs squares of every $(1 + m)$ already in our set! Look what happens to **$m_i + m = (1 + m) + L P_N$**: because $(1 + m)^2 \mid L$, $(1 + m)$ factors out cleanly **coprime** to the giant quotient $q$, leaving $D(m_i + m) = D(1 + m) \cdot D(q)$—where $q$ is built exclusively out of **huge primes $> p_N$**, keeping $D(q)$ arbitrarily close to **$1.000$**!

> [!PROOF]
> Note $D(n) = \frac{\sigma(n)}{n}$ is multiplicative on coprime numbers ($\gcd(u, v) = 1 \implies D(uv) = D(u) D(v)$), obeys $D(p^e) = 1 + \frac{1}{p} + \dots + \frac{1}{p^e} < \frac{p}{p - 1}$, and never exceeds $D(u)D(v)$ even when factors overlap.
>
> Start with $M_1 = \{1\}$ (here $1 + 1 = 2$, and $D(2) = \frac{1+2}{2} = 1.5 < 2$, so $2$ is deficient). Given a valid finite set $M_{i-1} = \{m_1, \dots, m_{i-1}\}$ (with $1 \in M_{i-1}$, so every $1 + m = 1 + m \in M_{i-1} + M_{i-1}$ is already deficient with $D(1+m) < 2$!), set:
> $$L = \prod_{m \in M_{i-1}} (1 + m)^2, \qquad m_i = L \cdot p_1 p_2 \cdots p_N + 1,$$
> choosing $N > \max_{m \in M_{i-1}}(1 + m)$ large enough as below:
> 1. **Check the self-sum $2 m_i$**: Notice $m_i \equiv 1 \pmod{p_j}$ for all $j = 1 \dots N$, so every prime factor of $m_i$ strictly exceeds $p_N$! Because every prime dividing $m_i$ is $> p_N \ge N$, how many distinct prime factors can $m_i < L \cdot p_1 \cdots p_N + 1 \le L \cdot p_N^N$ hold? Fewer than $N + \log_2 L$ distinct primes! Hence:
>    $$D(2 m_i) = D(2) D(m_i) \le \frac{3}{2} \prod_{q \mid m_i} \frac{q}{q - 1} \le \frac{3}{2} \left(1 + \frac{1}{p_N}\right)^{N + \log_2 L}.$$
> 2. **Check every cross-sum $m_i + m$ ($m \in M_{i-1}$)**: Write $m_i + m = (1 + m) + L P_N$. Because $(1 + m)^2$ divides $L$, pulling out $(1 + m)$ gives $m_i + m = (1 + m)\cdot q$ where $q = 1 + \frac{L}{1 + m} P_N$ is **divisible by NO prime Dividing $1 + m$ and NO prime $\le p_N$**! Therefore $\gcd(1 + m, q) = 1$, and $q \le m_i$ again has fewer than $N + \log_2 L$ prime factors, all $> p_N$:
>    $$D(m_i + m) = D(1 + m)\, D(q) \le D(1 + m) \left(1 + \frac{1}{p_N}\right)^{N + \log_2 L}.$$
> 3. **Why the prime-gap inflation factor vanishes as $N \to \infty$ (Lesson 9.1)**: By the Prime Number Theorem ($p_N \sim N \log N$, so $p_N / N \to \infty$) while $L$ is held fixed relative to $N$, we have:
>    $$\left(1 + \frac{1}{p_N}\right)^{N + \log_2 L} \le \exp\left(\frac{N + \log_2 L}{p_N}\right) \xrightarrow{N \to \infty} e^0 = 1.$$
>    Since $\frac{3}{2} < 2$ and every $D(1 + m) < 2$, picking $N$ large enough pushes every product strictly below $2$! Repeating forever yields an infinite deficient-sumset $M = \bigcup_{i \ge 1} M_i$.

## Python Check on Deficient Sumsets

Let us watch the first $3$ elements of this recursive primorial construction (`[1, 25, 567841]`) in Python and verify all $6$ pairwise sums have $\sigma(a+b)/(a+b) < 2$:

```python
import math

def sigma(n):
    s = 0
    for d in range(1, int(n**0.5) + 1):
        if n % d == 0:
            s += d + (0 if d * d == n else n // d)
    return s

# First 3 elements of the recursive deficient-sumset construction
M = [1]
primes = [2, 3, 5, 7, 11, 13, 17]
for N in [2, 4]:
    P = 1
    for p in primes[:N]:
        P *= p
    L = 1
    for a in M:
        L *= (a + 1) ** 2
    cand = L * P + 1
    if all(sigma(cand + a) < 2 * (cand + a) for a in M + [cand]):
        M.append(cand)

print("Constructed deficient-sumset prefix:", M)
for i in range(len(M)):
    for j in range(i, len(M)):
        val = M[i] + M[j]
        print(f"  {M[i]} + {M[j]} = {val}: sigma(val)/val = {sigma(val)/val:.4f} < 2")
```

```output

  1 + 25 = 26: sigma(val)/val = 1.6154 < 2

```

## Quick Self-Check Exercises

1. In CMI Problem 4, why would Hall's condition fail if Red components had size $3$ and Blue components had size $2$? Why was the padding step to equal size $\ell = k - 1$ essential?
2. Check whether `6` and `12` are deficient, perfect, or abundant—and why `{1, 5}` fails as a deficient-sumset!

<details>
<summary>Show Solutions to Self-Check Exercises</summary>

1. If one Red block has size $3$ and Blue blocks have size $2$, $1$ Red block needs at least $\lceil 3/2 \rceil = 2$ Blue neighbors (good!), EXCEPT if Red blocks have size $2$ and Blue blocks have size $4$, then $2$ Red blocks ($4$ elements!) could fit completely inside **one** Blue block ($1 < 2$), breaking Hall's condition $|N(S)| \ge |S|$! Making *every* Red and Blue block have the exact same size $\ell$ guarantees $j\ell$ elements hit at least $j$ target blocks every single time!
2. Divisors of $6$: $1 + 2 + 3 + 6 = 12 = 2 \times 6$ (**perfect**, *not* strictly $< 2n$!). Divisors of $12$: $1 + 2 + 3 + 4 + 6 + 12 = 28 > 24$ (**abundant**). Therefore `{1, 5}` fails immediately because $1 + 5 = 6$ is not deficient! Notice how `{1, 25}` works cleanly: $1+25 = 26$ has $\sigma(26) = 1 + 2 + 13 + 26 = 42 < 52$, and $25 + 25 = 50$ has $\sigma(50) = 1 + 2 + 5 + 10 + 25 + 50 = 93 < 100$!
