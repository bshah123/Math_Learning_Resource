## 1. Real Schur Form & Nilpotent Matrices (`P5` & `P6`)

In Linear Algebra, not every matrix with real eigenvalues can be diagonalized! For example, the $2 \times 2$ shear matrix $\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$ has both eigenvalues equal to $0$, yet it is *not* the zero matrix—there are simply not enough linearly independent eigenvectors to fill $\mathbb{R}^2$.

How do mathematicians fix that without leaving real numbers? Instead of asking for a *diagonal* matrix, ask only for an **upper triangular** matrix (**all zeros below the main diagonal**)!

> [!THEOREM]
> **Real Schur Decomposition & Cayley–Hamilton Consequences**
> 1. **Real Schur Theorem**: If an $n \times n$ real matrix $A$ has **only real eigenvalues** $\lambda_1, \dots, \lambda_n$, there exists an orthogonal matrix $Q$ ($Q^{\mathsf{T}} Q = I$, i.e., $Q^{-1} = Q^{\mathsf{T}}$) such that:
>    $$T = Q^{\mathsf{T}} A Q$$
>    is **upper triangular**, with $\lambda_1, \dots, \lambda_n$ sitting down the main diagonal! *(Proof idea: pick one unit eigenvector $q_1$ for $\lambda_1$, extend to an orthonormal basis, so $A$ in that basis has first column $[\lambda_1, 0, \dots, 0]^{\mathsf{T}}$; induct on the remaining $(n-1) \times (n-1)$ bottom-right corner!)*
> 2. **Why diagonal powers stay clean**: Whenever $T$ is upper triangular, $T^k$ is *also* upper triangular and its $(i, i)$ diagonal entry is simply $\lambda_i^k$!
> 3. **Nilpotent + Symmetric $\implies$ Zero (`P6` killer move)**: If every eigenvalue of $A$ is $0$, $T$ is strictly upper triangular (zeros on and below diagonal), forcing $T^n = 0$ and thus **$A^n = 0$** (Cayley–Hamilton). And if a matrix $A$ is *also* symmetric ($A = A^{\mathsf{T}}$), then $\sum_{i,j} A_{ij}^2 = \operatorname{tr}(A^{\mathsf{T}} A) = \operatorname{tr}(A^2) = \sum \lambda_i^2 = 0$, locking **$A = 0$**!

Also notice why squaring any real symmetric matrix produces a **positive semidefinite (PSD)** matrix (`P5`): for any vector $x$, $x^{\mathsf{T}} M^2 x = (Mx)^{\mathsf{T}} (Mx) = \|Mx\|_2^2 \ge 0$! So every eigenvalue of $(B - 1012 I)^2$ is guaranteed $\ge 0$.

## 2. Cyclic Residues Modulo Prime $p$ & Euler's Criterion (`P16`)

Let $p$ be an odd prime, and consider the $p - 1$ nonzero remainders $\mathbb{F}_p^* = \{1, 2, \dots, p - 1\}$ under multiplication modulo $p$.

> [!INTUITION]
> **Every Prime Modulo World Behaves Like Rotations Around One Wheel**
> By Gauss's Primitive Root Theorem, $\mathbb{F}_p^*$ is always a **cyclic group** of order $p - 1$: there exists a generator $g$ whose powers $g^0, g^1, \dots, g^{p-2}$ visit every nonzero remainder once before looping back ($g^{p-1} \equiv 1 \pmod p$). Notice what happens when $p - 1 = d \cdot k$: raising every element of $\mathbb{F}_p^*$ to the **$d$-th power** ($i^d \bmod p$) wraps $d$ times around the smaller subgroup $H = \{y \in \mathbb{F}_p^* : y^k \equiv 1 \pmod p\}$ of size $k$, hitting every element of $H$ **exact $d$ times**!

Let us check a tiny concrete case before jumping to `2017`! Take $p = 13$ ($p - 1 = 12 = 4 \cdot 3$, so $d = 4, k = 3$):
- Raise $1, 2, \dots, 12$ to the 4th power mod $13$: only **$k = 3$ values** ever appear: `{1, 3, 9}` (the roots of $y^3 \equiv 1 \pmod{13}$!), and each of `{1, 3, 9}` gets hit **$4$ times**!
- Because the polynomial $T^k - 1$ has roots equal to all $k$ elements of $H$, modulo $p$ it factors identically as:
  $$T^k - 1 \equiv \prod_{y \in H} (T - y) \pmod p.$$
  And whenever $k$ is **even**, pairing $y$ with $-y$ inside $H$ gives $\prod_{y \in H}(T + y) \equiv T^k - 1 \pmod p$ too!

How do we evaluate $a^{(p-1)/2} \bmod p$ quickly?
- **Euler's Criterion**: For any integer $a$ with $p \nmid a$, $a^{(p-1)/2} \equiv \left(\frac{a}{p}\right) \pmod p$, where the **Legendre symbol** $\left(\frac{a}{p}\right)$ is $+1$ if $a$ is a square mod $p$ and $-1$ if it is not!
- **Law of Quadratic Reciprocity** (for distinct odd primes $q, p$):
  $$\left(\frac{q}{p}\right) = \begin{cases} \left(\frac{p}{q}\right) & \text{if } p \equiv 1 \pmod 4 \text{ or } q \equiv 1 \pmod 4, \\ -\left(\frac{p}{q}\right) & \text{if } p \equiv q \equiv 3 \pmod 4. \end{cases}$$
  Notice how cleanly that computes $\left(\frac{5}{2017}\right)$ in `P16`: both $5 \equiv 1 \pmod 4$ and $2017 \equiv 1 \pmod 4$, so flip freely to $\left(\frac{2017}{5}\right) = \left(\frac{2}{5}\right) = -1$ ($2$ is not a square mod $5$, since squares mod $5$ are only $0, 1, 4$)!

## 3. Finite-Graph Martingales & Optional Stopping (`P18`)

Suppose a random game updates state step by step, and you track a score $M_t$ that is **completely fair in expectation**: given everything known up to step $t$ (written $\mathcal{F}_t$), its expected value tomorrow equals its exact value today:
$$\mathbb{E}[M_{t+1} \mid \mathcal{F}_t] = M_t.$$
Such a fair sequence $(M_t)_{t \ge 0}$ is called a **martingale**.

> [!THEOREM]
> **Optional Stopping on Bounded Finite Processes**
> Suppose $(M_t)$ is a bounded martingale on a finite graph that is guaranteed to terminate (reach an absorbing consensus state) at some random stopping time $\tau$ with probability $1$. Then the expected final score equals the starting score:
> $$\mathbb{E}[M_\tau] = M_0.$$

Suppose consensus only has two possible endings: all-White (score $M_{\max}$) with probability $p$, or all-Black (score $0$) with probability $1 - p$. Then Optional Stopping reads $p \cdot M_{\max} + (1 - p) \cdot 0 = M_0$, giving the winning probability in one division: $p = \frac{M_0}{M_{\max}}$!

## 4. Python Verification of All Three Primer Tools

Let us test a non-diagonalizable nilpotent matrix, the 4th-power subgroup modulo $13$, and a fair coin-flip gambler's ruin martingale (`M_0 = 2`, absorbing at `0` or `5`) in Python:

```python
import random

# 1. Nilpotent upper-triangular shear T has T != 0 but T^2 = 0 (real eigenvalues 0, 0)
T = [[0, 1], [0, 0]]
T2 = [[sum(T[i][k] * T[k][j] for k in range(2)) for j in range(2)] for i in range(2)]
print("Shear T^2:", T2, "tr(T^T T) =", sum(x*x for row in T for x in row))

# 2. 4th powers mod 13 (13 - 1 = 4 * 3) hit {1, 3, 9} four times each
powers = [pow(i, 4, 13) for i in range(1, 13)]
counts = {v: powers.count(v) for v in sorted(set(powers))}
print("4th powers mod 13:", counts)

# 3. Gambler's ruin martingale: start at 2, target 5 -> exact win prob = 2/5 = 0.40
random.seed(11)
wins, trials = 0, 10000
for _ in range(trials):
    m = 2
    while 0 < m < 5:
        m += 1 if random.random() < 0.5 else -1
    if m == 5:
        wins += 1
print(f"Martingale ruin (start=2, cap=5): sim={wins/trials:.4f}, exact={2/5:.4f}")
```

```output
Shear T^2: [[0, 0], [0, 0]] tr(T^T T) = 1
4th powers mod 13: {1: 4, 3: 4, 9: 4}
Martingale ruin (start=2, cap=5): sim=0.4069, exact=0.4000
```

## Quick Self-Check Exercises

1. Without computing $3^{10} \bmod 11$ by hand, use Euler's Criterion and squares mod $11$ ($1^2=1, 2^2=4, 3^2=9, 4^2=5, 5^2=3$) to determine $3^5 \bmod 11$!
2. On a fair random walk starting at $M_0 = 3$ with absorbing walls at $0$ and $10$, what is the exact probability of hitting $10$ before $0$?

2. Since $M_t$ is a bounded martingale, $\mathbb{E}[M_\tau] = M_0 = 3$. Writing $10 \cdot p + 0 \cdot (1 - p) = 3$ gives $p = \frac{3}{10} = 0.30$!
